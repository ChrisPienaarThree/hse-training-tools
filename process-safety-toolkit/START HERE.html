Saving your work on this USB stick – please read

  • Each tool keeps your work automatically in the browser of the computer you are using. That copy does not travel with the USB stick.
  • To keep a study on the stick: in the tool use File ▸ Save as… (link file) and save into the My studies folder. From then on every change is written to that file.
  • On another computer: open the tool from the stick and use File ▸ Open file… to open your study from My studies. If the tool asks, click Reconnect file.
  • Use File ▸ Download backup from time to time as a second copy. Always eject the USB stick safely before removing it.

Examples

  • Every tool has its examples built in – File ▸ Load example… (the Event Tree and Bow Tie tools open with the conveyor-fire example).
  • The Examples folder holds the same examples as files – open them with File ▸ Open file…. The fault tree file can also be imported into the Event Tree and Bow Tie tools with File ▸ Import fault tree.
  • Complete worked PHA – Hadeed natural gas distribution network (Examples/Hadeed Gas Network PHA): one study carried through every tool – HAZOP (8 nodes, 46 deviations) in the HAZOP Study Manager and both workbooks, FMECA workbook, 3 fault trees, 2 event trees and 2 bow ties that share the same tags, node numbers and recommendations. Start with the PHA study report (PDF); Cross-link test results.txt shows the 437 automated consistency checks.
  • All example data are illustrative – replace them with site and vendor data before use.

Excel workbooks (Workbooks folder)

Companion workbooks for teams that prefer Excel. Open them in Microsoft Excel (desktop) from the stick, or copy them to your computer first. Use File ▸ Save As to keep a filled-in copy in My studies.

WorkbookVersionWhat it contains
HAZOP Study Workbook.xlsx – no macrosCover, PSI register, nodes, guideword lists, 5×5 risk matrix, one worksheet per node – one row per deviation, cause and safeguard pick-columns joined into one cell, IPL per safeguard
HAZOP Study Workbook (macros).xlsm – enable macrosSame, with a multi-select cause drop-down (each pick adds a line), double-click safeguard entry with IPL / non-IPL, and AddNodeSheet
FMECA Workbook.xlsx – no macrosCover, reference documents, systems, equipment register, failure-mode library (29 equipment types, ISO 14224 modes), S / O / D 1–10, RPN, Action Priority, summary, one sheet per system
FMECA Workbook (macros).xlsm – enable macrosSame, with multi-select causes and detection methods, and AddSystemSheet (adds the Summary row automatically)

Macro versions: click Enable Content / Enable Macros when opening. Some organisations block macros in files from USB drives or e-mail – then use the .xlsx versions, or copy the file to a trusted location. If the folder came from a downloaded or e-mailed .zip and Windows Excel says macros are blocked because the source is untrusted: close Excel, right-click the .xlsm file ▸ Properties ▸ tick Unblock ▸ OK. The links open the files with the program your computer uses for Excel files.

Reference (Reference folder)

  • HAZOP guidewords, deviations and potential causes – chemical, steel & metals industries: Word · PDF – table of Parameter – Deviation – Potential causes for process parameters, steel & metals parameters, auxiliary and overview guidewords; causes tagged [C] chemical / [S] steel & metals. The same lists drive the drop-downs in the HAZOP Study Manager and the HAZOP Study Workbook.

Requirements

  • Windows 10 / 11 or macOS with a current Google Chrome or Microsoft Edge (recommended – needed for saving directly to files). Firefox and Safari work with Download / Import backup.
  • For the workbooks: Microsoft Excel 2016 or later (Windows or Mac; Microsoft 365 recommended). The macro versions need the desktop version of Excel – macros do not run in Excel for the web or on tablets.
  • No installation, no administrator rights and no internet connection are needed. Nothing is sent anywhere – all data stay on the computer and the stick.
  • If your company blocks files opened from USB drives, copy the whole folder to the computer (e.g. Documents) and run it from there.
