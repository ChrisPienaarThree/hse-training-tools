Hot DRI conveyor fire – the built-in example in all four tools. The HAZOP finds “no flow – stoppage under load”, the fault tree quantifies the N2 fire protection (gate G-002, PFDavg 0.0285), the event tree uses that gate as a heading, and the bow tie uses it as a barrier.

1. What this toolkit is

Four tools for recording and calculating a process hazard analysis (PHA): the HAZOP Study Manager, the Fault Tree & PFD Calculator, Event Tree Analysis and Bow Tie Analysis. They are study-recording tools and calculators, not simulators: what you enter is your study record. Around them are the HAZOP and FMECA Excel workbooks, the HAZID checklist, the HAZOP guidewords, user guides and worked examples.

Each tool is one HTML page that runs in the browser with no installation and no internet connection. Nothing you type is sent anywhere.

2. Quick start

  1. Read the overview (6 pages) if the tools are new to you.
  2. On Launch, choose a tool and click Open here (or Open in new tab).
  3. Try the built-in example first: File ▸ Load example.
  4. Start your own study with File ▸ New, then save it to a file straight away (section 4).

3. The views on this page

  • Launch – the four tools, the overview and quick links.
  • Open a tool – the tool on this page, with its purpose, quick start, examples and saving notes beside it. Switch tools with the selector at the top.
  • Study path – the order of a full PHA, what each step hands to the next, and which tool answers which question.
  • Library – guides, reference, workbooks and example files.
  • Guide – this page.

Hold the mouse over any button or link for a short tip.

4. Saving your work

Every tool keeps your work automatically in the browser of the computer you are using. That copy stays on that computer and in that browser only. Keep a file as well:

  • Link a file (Chrome or Edge): File ▸ Save as… (link file) – the HAZOP tool calls it Save study as…. From then on every change is written to that file. To carry on later, or on another computer, use File ▸ Open file…; if the tool asks, click Reconnect file.
  • From a USB stick or a folder: save into the My studies folder. Linking a file works only when the tool has its own tab – use Open in new tab. On the Open a tool view the browser blocks it.
  • On the website: linking a file also works on the Open a tool view. Save to your own computer or network drive.
  • Backup: File ▸ Download backup (.json) from time to time; Import backup brings it back. This works in every browser.
  • Always eject the USB stick safely before removing it.

5. Moving results between tools

  • Fault tree → event tree / bow tie: File ▸ Import fault tree (.fta.json)…, then link an event-tree heading or a barrier to a fault-tree gate; its probability is then calculated, not typed.
  • HAZOP → fault tree: a deviation with a high risk and a claimed IPL is a candidate for a fault tree of that safeguard. Keep the HAZOP node, deviation and recommendation numbers in the fault tree's title and notes.
  • FMECA → fault tree: failure modes of protective equipment become the basic events; use the same equipment tags.
  • Results → HAZOP: write the calculated frequency back into the HAZOP likelihood and recommendations.

The steel works gas network example shows all of these links in one study.

6. Browsers, phones and tablets

  • Best in Google Chrome or Microsoft Edge on a laptop or desktop.
  • Firefox and Safari work, but cannot link a file – use Download / Import backup.
  • On phones and tablets this page works, and the tools open, but their tables and diagrams are made for a wider screen. Use them there for viewing and small edits.

7. Problems and answers

  • “Save as… (link file)” does nothing or shows an error – use Chrome or Edge, and open the tool in its own tab (Open in new tab)allow the browser to save when it asks.
  • My study is not there on another computer – browser storage does not travel. Open your saved file with File ▸ Open file….
  • The tool asks to reconnect the file – the browser needs your permission again after a restart. Click Reconnect file.
  • Macros are blocked in the workbooks – see the note under Excel workbooks in the Library.
  • Starting a new class – each learner saves to their own file; old work in the browser can be cleared with File ▸ New in each tool.
