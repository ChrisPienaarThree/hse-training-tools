RCA Fault Tree

Cause-and-effect fault tree for root cause analysis. Every branch is a hypothesis to confirm or rule out with evidence. Optional probabilities rank the open hypotheses.

  • Look-up library: IPL PFDs, human error, equipment failure, initiating frequencies; every value editable
  • Credible causal combinations, P(cause | incident)
  • Tank overfill worked example

Which tool when

A typical investigation

1. Storyline Casebook
Record the initial report, secure and log evidence, and build the events-and-conditions storyline. Code causal factors with ICAM.
2. Tripod Beta
For a barrier-failure view: trios, failed and missing barriers, and the human-factors path from Immediate Cause to Underlying Cause and BRF.
3. RCA Fault Tree
For technical failures or several competing explanations: lay out every way the event could occur, test each branch, and use probabilities to decide what to test first.
4. Back to the Casebook
Export a Casebook package from Tripod or the fault tree and import it, so the root causes and actions sit in one case file and report.
Important

Saving your work on this USB stick

  • Each tool keeps your work automatically in the browser of the computer you are using. That copy does not travel with the stick.
  • To keep a case on the stick, use Save to file (Tripod), File ▸ Save as (RCA Fault Tree) or Save to file in the workspace bar (Casebook), and choose the My cases folder. From then on every change is written to that file.
  • On another computer, open the tool from the stick and open the file from My cases, or open it from the case register here. If a tool shows Reconnect file, click it: the browser asks for permission again after a restart.
  • Rows marked This computer only below are not on the stick yet.
  • Use Google Chrome or Microsoft Edge. Firefox and Safari run the tools, but they can only download and re-open copies, not keep a file linked.
  • Eject the USB stick safely before removing it.
