    Bernoulli along the board

    p/ρg + v²/2g + z = constant − losses

    Each piezometer tube shows static head p/ρg. Add the velocity head and you get the energy line. Where the bore narrows the fluid speeds up and the static head falls; where it widens the static head recovers. The energy line only ever falls.

    Friction in straight pipe

    hf = f · (L/D) · v²/2g    Re = ρvD/μ

    The tubes fall in a straight line: loss is proportional to length. Double the flow and the loss roughly quadruples in turbulent flow.

    Minor losses

    hL = K · v²/2g    Kexp = (1 − A₁/A₂)²    Kcon ≈ 0.5(1 − A₂/A₁)

    Each fitting is a loss coefficient on the local velocity head. Elbows add up; a standard elbow costs about 0.9 velocity heads, a long-radius one about 0.3.

    Flow measurement

    Q = Cd · At · √(2ΔP / ρ(1 − β⁴))    β = d/D

    Orifice and venturi read the same physics with different discharge coefficients (about 0.61 and 0.98) and very different permanent losses: the orifice throws most of its ΔP away, the venturi recovers it.

    System curves

    ΔP = K · ρv²/2 = K · ρ/2 · (Q/A)² ∝ Q²

    Every element's ΔP–Q curve is a parabola through the origin in fully turbulent flow. The curve you trace with the auto-sweep is the element's contribution to the system curve a pump has to overcome.

    About the rig data

    [Illustrative rig data, for training only.] Main line DN40 (41.9 mm bore), board length 2.0 m, taps T1–T6, supply from the same 4 kW pump as the Hydraulic Loop Bench. Discharge coefficients are textbook values, not calibrated instrument data.

    How to use the board

    • Pick an element from the board. Its options appear beside it: throat ratio for the meters, downstream or upstream bore for the steps, number and type of elbows, opening for the valve.
    • Set the flow with the supply pump and the downstream throttle. The piezometer tubes rise and fall with the pressure at each tap; the green line is the energy line.
    • Read ΔP between T2 and T4 across the element, and the permanent loss between T1 and T6. For the meters, the inferred flow is compared with the reference flowmeter.
    • Record or auto-sweep to trace the element's ΔP–Q curve on the chart.
    • Break it. Push a venturi hard with warm fluid to cavitate the throat; run an orifice at very low flow to see its coefficient drift; block a tap and see what a stale reading does to the profile.
