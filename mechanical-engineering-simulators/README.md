# Mechanical engineering training — simulators

Standalone, offline simulators for classroom and self-study use. Every simulator lives in its own folder under
`simulators/`, opens by double-clicking `index.html` (no server, no internet needed), works on a projector in
light or dark theme, and shows failure modes as well as normal operation.

`simulators/manifest.json` lists every simulator with its inputs, outputs and JavaScript API so a dashboard can
later embed several of them (iframe + `postMessage`) and read or drive them from one screen.

## Launch centre (`index.html` in this folder)
Open `index.html` to get the dashboard: a card per simulator with progress, "Run here" (embedded with live readouts, presets and task tracking in a side panel), "Open in new tab" for a projector, a side-by-side view of any two simulators, and a suggested classroom sequence. It reads `simulators/manifest.js` (generated from `manifest.json`; keep both in step) and talks to each simulator through `postMessage`. Task progress is stored in the browser only.

## Conventions (carried from the AI-in-HSE simulations)
- `index.html` + `app.js` + `styles.css`; `build()` called at the end of the script; no `fetch`, data inline.
- Theme tokens in `:root`, dark via `prefers-color-scheme` and `data-theme`; big type; keyboard control.
- Every number that a learner could memorise is illustrative and marked so in the "Behind the numbers" tab.
- Dashboard API: `window.<Name>.getState()` / `.setState({...})`; messages `sim:get` → `sim:state`, `sim:set`.
